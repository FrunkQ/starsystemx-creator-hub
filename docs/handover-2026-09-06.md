## What this is

The StarSystemX Creator Hub is the map-sharing funnel for Star System Explorer (SSE): people
upload a star system or a campaign starmap, the hub reviews its pictures, shows a page with a
cover and a filterable tree of what is inside, and hands anyone a one-click download that opens
in the app. It is a SvelteKit 2 / Svelte 5 app on a Cloudflare Worker, with Supabase Postgres
(over PostgREST, service-role key) and two R2 buckets. Its own repo, `C:\Development\starsystemx-creator-hub`.
Not a worktree of anything.

**The funnel is the product.** Every page exists to get a bundle into somebody's SSE. Discovery,
stars, comments, badges and the rest serve that; nothing here renders a map.

## The traps, so you do not re-hit them

- **Workers have no Canvas and no runtime WASM.** The cover is a pure-JS rasteriser and PNG encoder.
- **`response.headers.set` fails silently on a Worker response** - clone it (hooks).
- **supabase-js never throws on a write**; it returns `{ error }`. Check it. An upsert's
  `onConflict` must name the REAL primary key (`tests/schema.test.ts` pins them).
- **A deploy runs ahead of a migration.** Writes drop a column the database names (`tolerantWrite`);
  list reads drop an optional column (`tolerantSelect`, `server/cards.ts`); single rows are read
  with `select('*')`. Keep that discipline for any new column.
- **Never restore state in an `$effect` that also writes it** - it locked every page once (0.10.1).
  Use `onMount`.
- **The Bash tool mangles backslashes and a parse error aborts the whole command.** Use the Write
  and Edit tools for files with backslashes; check exit codes yourself (a piped `tail` hides them).
- **Stop any local preview server before `npm run build`**: it holds `.svelte-kit/cloudflare` and
  the adapter's final step fails with EPERM.
- **The local dev server has no `platform.env`**, so pages needing Supabase only render on the
  deploy. Verify against the live site with the Browser pane or `curl`.
- **Discord's OAuth redirect is the request origin** (`url.origin + '/api/link/discord/callback'`),
  so register one redirect per hostname the hub is served from.

  Measured at 404 from Vercel (`X-Vercel-Error: DEPLOYMENT_NOT_FOUND`) in the afternoon; the owner

  email and password through the API and is unaffected by either.

  R-18 asks for the door, `docs/prompt-for-sse-2026-09-06.md` is the prompt. When it ships, delete
